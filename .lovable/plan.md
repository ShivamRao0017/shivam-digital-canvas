# Shivam Yadav Portfolio

## Goal
Build a premium, Apple-inspired single-page portfolio that presents Shivam honestly as a first-year CSE (AI/ML) student: curious, actively learning, experimenting, and beginning to build.

## Experience
- Open with a full-viewport, typography-led introduction: “Hi, I’m Shivam.”
- Use restrained black, white, and neutral tones with generous whitespace, crisp hierarchy, rounded surfaces, soft shadows, and selective glass effects.
- Keep navigation minimal and make the page flow naturally through About, Learning, Interests, and Projects.
- Use subtle scroll reveals, gentle depth, and polished transitions while respecting reduced-motion settings.
- Close with a simple invitation to connect without inventing an email address or social profile.

## Content
- Present JECRC University and B.Tech CSE (AI/ML) prominently but without implying professional seniority.
- Turn the supplied skills into an honest learning timeline/status display:
  - C fundamentals
  - AI-assisted website development
  - Python in progress
  - Python libraries under exploration
  - AI/ML interests
- Frame project content as current experiments and future builds rather than completed professional work.
- Avoid fabricated metrics, employers, testimonials, awards, certifications, or years of experience.

## Visual Direction
- Strong sans-serif typography with oversized but readable headlines.
- Near-black and warm-white surfaces, subtle neutral contrast, minimal borders, and limited accent color.
- Editorial full-width sections rather than a generic developer-card grid.
- A bespoke abstract AI/code visual treatment will support the experience without impersonating a portrait.
- Ensure the next section remains visible beneath the opening area on common desktop and mobile screens.

## Technical Details
- Implement at `/` with semantic React and Tailwind v4 tokens defined in the global design system.
- Add route-specific title, description, Open Graph, and Twitter metadata.
- Add responsive navigation, accessible focus states, reduced-motion behavior, and semantic headings.
- Use only bundled/local visual assets and no external image hotlinks.
- Verify the finished page in the running preview at desktop and mobile widths.
